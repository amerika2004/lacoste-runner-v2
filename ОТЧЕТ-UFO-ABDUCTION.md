# Lacoste Runner — отчёт об обновлении механики НЛО

## Что изменено

### Сценарий события
- Убрана прежняя схема, в которой НЛО просто пролетало и сбрасывало независимые монеты.
- НЛО создаётся как световая точка в верхней части экрана.
- В течение `approachDurationMs` точка увеличивается и опускается к игровой позиции.
- После прибытия включается сканирующий луч.
- По завершении сканирования корабль уходит вверх и уменьшается.
- Секретная комбинация Konami запускает тот же сценарий принудительно.

### Кража еды
- В `game.js` добавлено событие `ufo_scan_food` после перемещения еды и до столкновений с игроком.
- `js/pack4.js` отбирает одну обычную единицу еды в зоне луча с заданным интервалом.
- Power-up объекты (`isPowerup`) не трогаются.
- Украденная еда удаляется из массива игрового мира и визуально перемещается к кораблю.

### Монеты
- За каждую украденную единицу еды создаётся физическая монета с номиналом 50.
- Баланс не увеличивается в момент кражи: награда добавляется только при столкновении монеты с игроком.
- Монета падает под гравитацией и останавливается так, что её нижняя граница совпадает с `groundY`.
- Высота земли пересчитывается при смене биома.
- Монеты перемещаются вместе с игровым миром, корректно обрабатывают обычную скорость и обратное перемещение при анимации удара.

### Перехват НЛО
- НЛО можно поймать только прыжком в фазе сканирования.
- За перехват начисляется 1000 монет.
- Открывается один случайный скин из каталога всех персонажей, которого ещё нет в `lacosteSkins` и который не выбран в `lacosteCurrentSkins`.
- Кандидаты дедуплицируются, поэтому повторно один и тот же скин не выпадает.
- Если каталог полностью открыт, игра не выдаёт дубликат; гарантированные 1000 монет сохраняются.

### Звуки
В `config.js -> GAME_CONFIG.audio.sfx` добавлены отдельные поля:
`ufoArrival`, `ufoBeam`, `ufoSteal`, `ufoCoinDrop`, `ufoCoinCollect`, `ufoSkinReward`.
Существующее `ufoCatch` используется для звука успешного перехвата. Все пути пустые, пользователь может назначить собственные файлы.

## Файлы для полной замены
- `config.js`
- `game.js`
- `js/pack4.js`

В архив замены также включены файлы предыдущей исправленной сборки и необходимые биомные SVG, чтобы не потерять ранее внесённые исправления.

## Проверки

Успешно:
- `node --check` для `config.js`, `game.js`, `menu.js` и всех `js/*.js`;
- автономная эмуляция обработки `GameEvents`;
- переход `arrival -> scan`;
- кража еды в зоне луча до проверки столкновения игрока;
- power-up не похищается;
- ограничение частоты похищения;
- одна украденная еда создаёт одну монету номиналом 50;
- монета приземляется на высоту `groundY - radius`;
- монета увеличивает баланс только при подборе;
- прыжок в корпус корабля даёт 1000 монет и новый скин;
- уже экипированный скин исключается из награды;
- последовательные поимки не дают один и тот же скин повторно;
- при полностью открытом каталоге дубликат не выдаётся;
- Canvas-отрисовка точки, корабля, луча, похищаемой еды и монет проходит тест с mock Canvas context.

## Ограничения проверки
Автоматические тесты выполнялись в Node VM с подменёнными браузерными API и mock Canvas. Синтаксис и логика событий подтверждены, но полноценную графическую сессию с настоящим браузерным рендерингом, React CDN и пользовательским вводом нельзя считать подтверждённой этими тестами. После установки нужно проверить размеры/позицию луча и корабля на фактическом игровом разрешении.

## Настройки баланса по умолчанию
- Вероятность встречи при старте: 5%.
- Прилёт из точки: 2800 мс.
- Длительность сканирования: 12000 мс.
- Интервал похищения еды: 850 мс.
- Награда за каждую еду: 50 монет.
- Награда за прыжок и поимку НЛО: 1000 монет + один новый скин.
