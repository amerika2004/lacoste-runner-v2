LACOSTE RUNNER — ИСПРАВЛЕННАЯ СБОРКА

Это полный проект, включающий исходные файлы и ресурсы с внесёнными исправлениями.
Запускайте index.html через локальный веб-сервер.
Перед заменой своей старой версии сделайте резервную копию папки.

Технические детали, список изменений, проверки и ограничения описаны в файле
ОТЧЕТ-ИСПРАВЛЕНИЙ.md.

Важно: реферальная/административная активация промокодов и глобальный рейтинг
требуют серверной части. В этой клиентской сборке небезопасная выдача наград
по произвольным строкам отключена, а таблица рекордов остаётся локальной.
