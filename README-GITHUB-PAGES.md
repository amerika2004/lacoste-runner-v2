# Lacoste Runner — публикация через GitHub Pages

## Быстрый запуск локально

Не открывайте `index.html` напрямую через `file://`. Запустите HTTP-сервер из корня папки проекта:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000

## Публикация

1. Создайте GitHub-репозиторий (или используйте существующий).
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `game.js`, `engine/`, `plugins/`, `js/`, `style.css`, `config.js`, `menu.js`, `source/ и остальные файлы проекта.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. После публикации откройте ссылку, показанную в разделе Pages.

` .nojekyll ` добавлен, чтобы GitHub Pages не пропускал файлы/папки, начинающиеся с подчёркивания.

## После публикации

- Подождите завершения GitHub Pages deployment.
- Выполните жёсткую перезагрузку страницы: `Ctrl + Shift + R`.
- Если ранее опубликованная версия закешировалась, проверьте страницу в приватном окне.
- В DevTools → Console проверьте отсутствие ошибок; в Network убедитесь, что скрипты и файлы из `engine/`, `plugins/` и `js/` загружаются со статусом 200.

## Проверки проекта

```bash
npm test
npm run check
```

Эти команды проверяют тесты движка и структуру исходников, но не заменяют проверку запуска в браузере после публикации.
