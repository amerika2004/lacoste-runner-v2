LACOSTE RUNNER — UFO ABDUCTION UPDATE
====================================

УСТАНОВКА
---------
1. Сделайте резервную копию папки игры.
2. Распакуйте архив в корневую папку игры.
3. Согласитесь на замену существующих файлов.
4. Откройте игру и обновите страницу сочетанием Ctrl+F5.

Архив содержит полные файлы, а не патчи:
- config.js
- game.js
- js/pack4.js
- остальные файлы предыдущей исправленной сборки, необходимые для сохранения прошлых исправлений.

НОВАЯ МЕХАНИКА НЛО
-----------------
1. В начале забега НЛО появляется с вероятностью 5% (настраивается в config.js).
2. Сначала в небе видна маленькая светящаяся точка. За 2.8 секунды она увеличивается и опускается до игровой высоты.
3. После прилёта НЛО включает луч и ищет обычную еду в игровом пуле.
4. Еда, попавшая в зону луча, удаляется до проверки столкновения с игроком и анимируется в сторону корабля.
5. После каждой украденной единицы еды НЛО выпускает монету номиналом 50.
6. Монета падает под действием гравитации, останавливается на поверхности земли (низ монеты совпадает с groundY) и собирается при столкновении с игроком. Баланс увеличивается только при подборе монеты.
7. Игрок может прыгнуть и коснуться корпуса НЛО во время фазы сканирования. За это начисляется 1000 монет и открывается один случайный скин, которого ещё нет в коллекции.
8. Power-up предметы луч не крадёт.
9. Если все скины уже открыты, игра не выдаёт дубликат: остаётся награда 1000 монет.

ТЕСТИРОВАНИЕ НЛО
----------------
НЛО появляется случайно с вероятностью 5% при старте забега.
Для гарантированного запуска используйте секретную комбинацию:
↑ ↑ ↓ ↓ ← → ← →
Комбинация запускает ту же новую механику НЛО.
Для временного теста можно поставить secrets.ufoChance = 1.0.
После теста верните значение 0.05.

НАСТРОЙКА ЗВУКОВ
----------------
Все звуки находятся в config.js -> GAME_CONFIG.audio.sfx.
Добавлены поля:
- ufoArrival      — точка появляется / корабль прилетает
- ufoBeam         — включение луча
- ufoSteal        — похищение единицы еды
- ufoCoinDrop     — выпадение монеты
- ufoCoinCollect  — подбор монеты
- ufoCatch        — поимка корабля
- ufoSkinReward   — получение нового скина

Пример:
ufoArrival: 'source/sounds/ufo-arrival.mp3'

Путь задаётся относительно index.html. Пустая строка отключает соответствующий звук.

ВАЖНО
